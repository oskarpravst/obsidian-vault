We usually want to navigate our computer using the terminal. We can achieve this by learning some basic commands:

```
pwd // where we are located

mkdir // make a new directory

ls 

ls -l // longer list

cd . // the dot represents the current file

cd .. // previous folder

cd / // root

ctrl + shift + t // new terminal
```
