# Algorithm

## Definition

An **algorithm** (*algoritem*) is a finite sequence of precise steps that solves a [[Problem|problem]]. It is the middle step of [[Programming|programming]]: problem → algorithm → [[Program|program]].

## Explanation

- An algorithm does not depend on the programming language. The same algorithm can be written in Java, Python or as a recipe.
- Different algorithms for the same problem can differ greatly in speed. We compare them with [[Big O Notation|big O notation]].

## Examples

- Searching: [[Linear Search|linear search]] $O(n)$ vs. [[Binary Search|binary search]] $O(\log n)$
- Primes: testing divisors vs. the [[Sieve of Eratosthenes|sieve of Eratosthenes]]
- [[Euclidean Algorithm|Euclidean algorithm]] for the greatest common divisor
- Minimising switching functions: the [[Quine–McCluskey Algorithm|Quine method]] (Digital circuits)
