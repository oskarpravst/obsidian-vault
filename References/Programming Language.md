# Programming Language

## Definition

A **programming language** (*programski jezik*) is a formal language for writing [[Program|programs]]. It is the bridge between natural language and the basic operations a computer can perform.

## Explanation

- **Compiled vs. interpreted:** Java source code must be compiled (`javac`) into bytecode before it runs, and the [[JVM]] executes the bytecode. Python, for comparison, is run directly by an interpreter.
- A language has a **syntax** (what is allowed to be written) checked by the [[Compiler|compiler]], and **types**: the compiler only sees types, not values.
