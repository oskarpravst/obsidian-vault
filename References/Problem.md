# Problem

## Definition

A **problem** is a task described in natural language that we want a computer to solve. It is the starting point of [[Programming|programming]]: problem → [[Algorithm|algorithm]] → [[Program|program]].

## Explanation

- Before writing code, a problem has to be understood: what the input is, what the output should be, and which **[[Boundary Condition|boundary conditions]]** and edge cases exist (e.g. the smallest and largest input).
- A big problem is split into smaller subproblems, which later become separate [[Method|methods]].
