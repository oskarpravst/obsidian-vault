# Programming

## Definition

**Programming** (*programiranje*) is turning a [[Problem|problem]] described in natural language into a solution a computer can execute:

$$\text{problem} \to \text{algorithm} \to \text{program}$$

## Explanation

- A computer can only perform basic operations. A [[Programming Language|programming language]] is the bridge between natural language and those operations. A [[Compiler|compiler]] translates the program towards the computer's [[Binary language|binary language]].
- First we find an [[Algorithm|algorithm]] (the steps of the solution), then we write it as a [[Program|program]].
- Programs grow in stages: first simple and repetitive, then with loops and [[Variable|variables]], then split into functions ([[Method|methods]]).
- Speed matters: an unoptimised program runs slowly, and the [[Processor|processor]] (frequency, number of cores) also affects the speed of execution.

## Examples

**Introduction to academic studies** (lecture 0): a pancake recipe as a program, the average of numbers in an array, and an upgrade with absolute values.
