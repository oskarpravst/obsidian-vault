# Program

## Definition

A **program** is an [[Algorithm|algorithm]] written in a [[Programming Language|programming language]], so that a computer can execute it. It is the last step of [[Programming|programming]]: problem → algorithm → program.

## Explanation

- A Java program is a sequence of statements in a class with a `main` [[Method|method]], where execution starts.
- Java source code (`Ime.java`) is first compiled with `javac` into bytecode, which the [[JVM]] executes (`java Ime`).
- **Errors:** the compiler finds syntax errors before the program runs (e.g. `';' expected`, with file and line). Exceptions happen while the program runs (e.g. `ArithmeticException: / by zero`). Fix only the first compile error, then recompile.
