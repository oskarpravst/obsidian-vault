# Razredi in objekti

tabela je zaporedje elementov istega tipa.
objekt je zaporedje elementov poljubnih tipov. spremenljivke imajo praviloma razlicen pomen(ampak imajo nekaj skupnega). pri objekti so spremenljivke atributi, do atributov dostopamo preko imen. Tip objekta podamo v razredu.
razred je konstrukt s katerim lahko povemo kako so sestavljeni posamezni objekti

objekti tudi pripadajo referencnim tipom.



tabela stolpcev 

```java
import java.util.Scanner;
import java.util.Arrays;

public class Stolpci {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt(); // stevilo vrstic

        int[][] stopnice = new int[n][];

        for (int i = 0; i < n; i++) {
            int[] vrstica = new int[i + 1];
            for (int j = 0; j <= i; j++) {
                vrstica[j] = j + 1;
            }
            stopnice[i] = vrstica;
        }

        for (int[] vrstica: stopnice) {
            System.out.println(Arrays.toString(vrstica));
        }
    }
}
```

```java
import java.util.Scanner;
import java.util.Arrays;

public class IndeksMaksimuma {
    public static void main(String[] args) {
        int[][] tabela = {
            {2, 3, -1, 4, 0},
            {7, -2, -4, 3, 8},
            {-6, 9, -3, 5, -7},
            {3, -1, -7, 6, 4}
        };

        int[] imax = iMaxPoStoplcih(tabela);
        System.out.println(Arrays.toString(imax));
    }

    public static int[] iMaxPoStoplcih(int[][] t) {
        int[] imax = new int[t[0].length];

        for (int j = 0; j < t[0].length; j++) {
            int iNaj = 0;
            for (int i = 1; i < t.length; i++) {
                if (t[i][j] > t[iNaj][j]) {
                    iNaj = i;
                }
            }
            imax[j] = iNaj;
        }

        return imax;
    }
}
```
